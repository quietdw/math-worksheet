# 首页学科入口

| 项 | 值 |
| --- | --- |
| 时间 | 2026-10-29 |
| 功能点 | 首页学科入口 |
| 涉及文件 | `index.html`、`assets/site.css` |
| 状态 | 已实现 |

## 规格

| 区块 | 内容 | 交互 |
| --- | --- | --- |
| 页头 | 由通用外壳注入 | 见 [通用外壳契约](./2026-10-29-通用外壳契约.md) |
| 站点标题区 | 站点名「小学练习题生成器」+ 一句话导语 | 无 |
| 学科入口 | 三张卡片：数学（已上线）、语文（建设中）、英语（建设中） | 整卡可点；数学跳转数学页，语文 / 英语跳转对应占位页 |
| 卡片内容 | 学科名、状态徽标、一句话说明、4 个题型标签、行动文案（`生成计算题 →` / `查看进度 →`） | 悬停整卡抬升 |
| 页尾 | 由通用外壳注入 | 见 [通用外壳契约](./2026-10-29-通用外壳契约.md) |

## 样式与文案要求

- 配色、字体、圆角沿用 `assets/site.css` 里的设计变量，不新增页面私有颜色。
- 宽度 ≥ 900px 时卡片三列并排，窄屏单列堆叠。
- 首页文案随页头语言开关切换，中英文案由页面内 `SiteShell.extendI18N()` 注册，页面自己不维护语言状态。
