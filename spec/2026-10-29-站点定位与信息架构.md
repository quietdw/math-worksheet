# 站点定位与信息架构

| 项 | 值 |
| --- | --- |
| 时间 | 2026-10-29 |
| 功能点 | 站点定位与信息架构 |
| 涉及文件 | `index.html`、`math-practice-generator.html`、`chinese-practice-generator.html`、`english-practice-generator.html`、`404.html`、`sitemap.xml`、`robots.txt` |
| 状态 | 已实现 |

## 1. 定位

零构建、纯静态的多学科小学练习卷站点：打开网页即可出题、排版、导出打印。所有计算在浏览器本地完成，不上传任何数据。

## 2. 信息架构

站点从单一「计算题生成器」扩展为多学科练习卷站点，首个落地学科为数学，语文与英语先占位。

| 路径 | 页面 | 状态 | 索引策略 |
| --- | --- | --- | --- |
| `/` | 首页（学科入口） | 已上线 | 收录，进 sitemap |
| `/math-practice-generator.html` | 数学练习卷生成器 | 已上线 | 收录，进 sitemap |
| `/chinese-practice-generator.html` | 语文练习卷 | 占位 | `noindex,follow`，不进 sitemap |
| `/english-practice-generator.html` | 英语练习卷 | 占位 | `noindex,follow`，不进 sitemap |
| `/404.html` | 自定义 404 | — | `noindex` |

约束：

- 首页只做入口，不承载出题逻辑；出题逻辑留在各学科页面内，页面之间互不依赖。
- 学科页面文件名统一为 `<subject>-practice-generator.html`，新增学科按同一命名扩展。
- 占位页不放参数面板和出题脚本，只保留静态说明与「去看已经能用的数学页」出口，避免用户走进死路。
- 所有页面共用外壳（页头 / 页尾），外壳是导航、GitHub 入口、主题、界面语言的唯一来源（见 [通用外壳契约](./2026-10-29-通用外壳契约.md)）。
