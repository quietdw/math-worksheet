# 语文练习页

| 项 | 值 |
| --- | --- |
| 时间 | 2026-10-29 |
| 功能点 | 语文练习页（按难度出题） |
| 涉及文件 | `chinese-practice-generator.html`、`assets/cn-bank.js`（超限时才拆）、`SPEC.md`、`sitemap.xml` |
| 状态 | 已定稿（待实现） |

语文页脱离占位状态，改为可出题、可排版、可导出的学科页。与数学页的差别在出题维度：数学按运算规则出题，语文按**年级 + 星级**双轴出题。

## 1. 范围

- 覆盖小学 G1–G6，题型七类：看拼音写词语、生字注音、同音字选字填空、组词、多音字选音、近义词 / 反义词、成语补全。
- 保留通用外壳（页头 / 页脚）与 `data-page="chinese"`；去掉 `noindex`，按可用页进 `sitemap.xml`。
- 页面自身管理参数、出题、预览、导出，不依赖首页或其他学科页。

## 2. 难度模型

### 2.1 双轴

| 轴 | 取值 | 作用 |
| --- | --- | --- |
| 年级 | G1–G6 | 限定字词候选池，硬边界，不做跨年级抽样 |
| 星级 | ★1–★5 | 认知负荷，由特征分数分桶得到 |

### 2.2 特征分

条目分 = 下列特征增量之和：

| 特征 | 增量 |
| --- | --- |
| 笔画 | ≤6 → 0；7–9 → 1；10–12 → 2；≥13 → 3 |
| 拼音难点 | 翘舌、平舌、前后鼻音、ü、零声母、长韵母各 +0.5（单字上限 2） |
| 年级 | (年级 − 1) × 1.2 |
| 字形结构 | 独体 0；左右 / 上下 / 半包围 1；品字与复合 2（P2 采集字形后启用，P1 不计入） |
| 单位长度 | 单字 0；双字词 1；三字 1.5；四字成语 2（P1 按 0.6 × (字数 − 2) 计入词语得分） |
| 题型负荷 | 抄写 0；注音 1；选择 1.5；填空 2；改写 / 排序 3（P1 以固定偏置近似：组词 +0.4、选择 +0.8） |

### 2.3 分桶

- 分桶按题型各自做：同一题型内对单元分做极值归一（0–100），按五分位切 ★1–★5。
- 桶边界在每次生成时按当前年级选择重算，不落盘、不进配置。
- 校准标准：抽 200 题人工标注，模型排序与人工标注的 Spearman ≥ 0.7（P1 未校准，用 `?selftest=1` 的星级分布代替回归）。

## 3. 题库

### 3.1 数据源

只用公版与通用材料：现代汉语常用字表、通用规范汉字表、自建成语与近反义词对。不抓取教材课文原文与课后练习。

字表另收人教统编小学语文生字表（一年级上册—六年级下册）：只取「字 + 拼音 + 年级」，按年级归并、不区分上下册，不取课文原文、课后练习与插图；笔画取自 Unicode Unihan `kTotalStrokes`，多音字只保留一个主读音（生字表首位，个别按小学常用读音调整），其余读音不参与出题。词语用脚本从通用词频表补齐（jieba `dict.txt`，非教材词表）：取词频 ≥ 800 的常用双字词，词性限名词 / 动词 / 形容词 / 成语类；词内每个字的年级不得高于目标字所在年级，避免高年级词混进低年级卷面；再用 pypinyin 校验词内读音与字表主读音一致（韵母基与调号都比对），排除多音字误配；政治、军事、暴力、疾病等敏感字词按字表与词表两级黑名单剔除。人工初排的 394 字词语保持不变，自动补词只填空缺。

### 3.2 结构

压缩元组，字段缺省即默认值；拼音直接带声调符号：

```js
{ c:'蜻', p:'qīng', s:14, g:3, words:['蜻蜓'] }
```

| 字段 | 含义 |
| --- | --- |
| `c` | 字 |
| `p` | 主读音（带声调符号，运行时拆成字母与声调） |
| `s` | 笔画数 |
| `g` | 起始年级 |
| `words` | 由该字构成的词，词内所有字必须也在表中 |

同音字、近反义词、成语、多音字读音不预先写进条目，改由 `pinyin.base` 分组派生：同音节（忽略声调）的字自动成为同一组，候选干扰项再从组内筛掉「能独立组成同一个词」的字，避免一题两解。

### 3.3 体积与拆分

- P1 已按模块拆分，不再坚持单文件：题库在 `assets/cn/bank.js`（`window.CN_BANK_TEXT`，一行一条），由 `core.js` 解析成索引；页面按顺序加载 `bank → core → types → engine → paper → app → selftest`。
- 全部为普通 `<script>`，不使用 ES module / import / fetch，`file://` 双击可用，仍保持零构建。
- 文件按 UTF-8 无 BOM + LF 保存。

## 4. 题型与星级放行

| 题型 | key | 星级 | 负荷 |
| --- | --- | --- | --- |
| 看拼音写词语 | `pinyin2word` | ★1–★2 | 抄写 |
| 生字注音 | `char2pinyin` | ★1–★2 | 注音 |
| 同音字选字填空 | `homophone` | ★2–★3 | 选择 |
| 组词 | `wordBuild` | ★2–★3 | 填空 |
| 多音字选音 | `polyphone` | ★3–★4 | 选择 |
| 近义词 / 反义词 | `synAnt` | ★3–★4 | 填空 |
| 成语补全 | `idiomFill` | ★4–★5 | 填空 |

题型以注册表组织，互不耦合：

```js
registerType({
  key: 'pinyin2word',
  stars: [1, 2],
  needs: ['word'],
  pick: function (pool, star, rng) { /* 从对应桶取样，避开已用条目 */ },
  build: function (item, star, rng) { return { stem: 'qīng tíng', answer: '蜻蜓', kind: 'write' }; },
  check: function (q) { /* 答案非空、唯一、干扰项不与答案同形同音 */ }
});
```

## 5. 出题引擎约束

- 引擎为纯函数，不碰 DOM；随机数走注入的 `rng`，默认 mulberry32。
- 种子：`cfg.seed` 参与每一次抽样，同 seed + 同配置生成同一张卷；界面提供复制 seed 入口。
- 配额：按题型分别设题量，合计等于总题量；某题型候选不足时按 `stars` 向下降级并在状态栏提示。
- 去重：同一字 / 词全卷默认出现 ≤1 次（可配 1–3）；同一拼音组不出现在相邻两题。
- 干扰项：来自同年级池、难度不低于目标星、与答案不同形不同音、题内不重复；不满足则重生，最多重试 8 次后降级。（P1 实现：同音节分组 + 排除「能独立组成同一词」的字，候选不足 2 个的条目直接不建单元。）
- 整卷难度曲线三选一：递增、均衡、混合（默认 基础 60% + 提升 30% + 挑战 10%）；生成后复核均分落在目标区间 ±0.5σ，越界重排。
- 答案判定不参与交互：语文卷只输出题目卷与答案卷，不做在线批改。

## 6. 排版与导出

- 版面沿用数学页：左侧 A4 预览 + 缩放（100% / 适应宽度），右侧参数面板分「题目内容」「难度」「排版与显示」三组。
- ★1–★2 的书写类题目题面使用田字格（CSS 背景网格，不用图片），拼音用四线三格；★3 以上用横线答题区。
- 排版参数：每行题数 1–4、题组间距、字号、表头（姓名 / 班级 / 日期 / 得分）、答案显示。
- 导出：打印 / 另存 PDF（`@media print` 隐藏外壳）、Word（docx.js 首次导出时按需加载，失败降级 `.html`）、独立 HTML。
- 拼装导出 HTML 时禁止出现连续的 `</body>`、`</script>` 字面量，用 `'</bo' + 'dy>'` 拼接。

## 7. 自检

`chinese-practice-generator.html?selftest=1` 在页内跑 200 个种子，输出：

- 卷内重复率、答案唯一率、干扰项冲突数；
- 各星级实际占比与目标占比偏差；
- 字表覆盖率（出过的字 / 池内字）、各题型失败重试与降级次数。

纯前端、零依赖、不写文件，作为唯一回归入口。

## 8. 验收标准

- 一次生成 20 张卷：无重复题、无缺答案、干扰项无冲突。
- 同一 seed 两次生成结果逐题一致。
- 三档曲线与七类题型的星级放行符合第 4 节表格。
- 打印预览中不出现页头页脚；Word / HTML 导出与预览内容一致。
- 深浅色、中英文切换在语文页生效，刷新后偏好保留。
- 控制台无报错。

## 9. 分期

| 阶段 | 交付 |
| --- | --- |
| P1 | 引擎 + 分桶 + ★1–★3 四类题型 + A4 预览 / 打印 / 答案卷 |
| P2 | ★3–★5 三类题型、G4–G6 补库、Word / HTML 导出、seed 分享 |
| P3 | 分层卷 A/B/C、错题重练 |

## 10. 风险

- 题库准确性是主要风险：拼音、笔画、结构、同音字需人工抽检，先小批量上线再扩量。
- 多音字与成语的干扰项最易产生歧义，校验器强制唯一答案，不通过不出题。
- 体积：全量字词超 200KB 时按 3.3 拆文件，拆分后仍保持零构建。
- 轻声未处理：词语拼音由字表主读音拼接，孩子、日子一类轻声词会按原调显示（hái zǐ），
  自动补词进一步放大了这个偏差，P2 需要给词语单独存拼音或加轻声规则。
