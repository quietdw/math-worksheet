# 语文英语占位页

| 项 | 值 |
| --- | --- |
| 时间 | 2026-10-29 |
| 功能点 | 语文 / 英语占位页 |
| 涉及文件 | `chinese-practice-generator.html`、`english-practice-generator.html` |
| 状态 | 已实现（占位） |

两页用同一模板，只替换学科名与题型预告文案：

| 元素 | 内容 |
| --- | --- |
| `<title>` | 语文练习卷生成器（建设中） - 小学练习题生成器 |
| 页头 | 通用外壳，导航中该学科带「建设中 / Soon」标记 |
| 正文 | 学科名 + 状态徽标、「题型还在规划」说明、规划中的题型清单（语文：看拼音写词语、看词语写拼音、生字注音、组词、近义词 / 反义词；英语：单词默写、中译英、英译中、选词填空、字母与音标） |
| 出口 | 正文底部一句「数学练习卷已可用：前往数学练习卷生成器」，链接到 `math-practice-generator.html` |
| 索引 | `<meta name="robots" content="noindex,follow">`，不进 sitemap |

页面保持在一个屏幕内可见的静态内容，不加载出题脚本、不引入参数面板。
