## 结构契约

学科练习页统一为「左预览 + 右参数面板」两栏骨架，骨架样式只存在于 `assets/worksheet.css`，页面样式文件不再重复实现：

- 载入顺序：`assets/site.css` → `assets/worksheet.css` → 页面私有样式（数学页内联 `<style>`、语文页 `assets/cn/cn.css`）。
- `worksheet.css` 负责：`html,body` 高度、`.app` 两栏网格、`.preview` 容器、缩放条（`.zoom-bar` / `.sheet-title` / `.zoom-inner` / `.zoom-btn` / `.zoom-val` / `.zoom-sep`）、`.paper-wrap`、`.panel` / `.panel-scroll` / `.panel-foot` 的骨架，以及响应式与打印布局。
- 页面私有样式只保留：试卷纸样（`.page`、`#paper`、题面排版）、预览区内外边距、面板内控件与文案排版、各页主题变量（`--preview-bg`、`--page-shadow` 等）。

## 参数项说明气泡

参数含义无法在一行内说清时（如「种子」），在 `.field-head` 内用 `.label-tip` 包裹标签并追加 `.tip`：

- 结构：`<span class="tip" tabindex="0" aria-describedby="对应气泡 id"><span aria-hidden="true">?</span><span class="tip-body" id="…" role="tooltip">说明</span></span>`。
- 样式只存在于 `assets/site.css`，两页共用；数学页用 `data-i18n` 切换文案，语文页用 `data-shell`。
- 默认隐藏，`:hover` / `:focus-visible` 显示，键盘可聚焦；气泡 `aria-describedby` 指回自身，读屏可获取说明。
- 气泡宽度上限 `220px`，靠左对齐，避免在窄面板里溢出。

## 断点与堆叠顺序

- 单断点 `1080px`：`> 1080px` 两栏（预览 `1fr` + 面板 `372px`）；`≤ 1080px` 单列。
- 单列时**预览在上、设置在下**（`.preview{order:1}`、`.panel{order:2}`）：先看到卷面，参数在下方完整展开，不再出现「数学设置在上、语文预览在上」的差异。
- 单列时 `html,body` 高度改为自适应，`.preview` 限高 `70vh` 内部滚动，`.panel-scroll` 取消内部滚动，由整页滚动承载；面板内容与面板底部按钮统一限宽 `720px` 居中。
- 打印时只保留试卷：`.app` 转块级、`.zoom-bar` 与 `.panel` 隐藏、`.preview` 取消背景与内边距，页面文件只补充纸样尺寸与分页规则。
