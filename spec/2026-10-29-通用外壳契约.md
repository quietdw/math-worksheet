# 通用外壳契约

| 项 | 值 |
| --- | --- |
| 时间 | 2026-10-29 |
| 功能点 | 通用外壳（页头 / 页尾） |
| 涉及文件 | `assets/site-shell.js`、`assets/site.css` |
| 状态 | 已实现 |

页头与页尾不各页复制粘贴，由 jQuery 模块统一注入。

| 位置 | 内容 | 归属 |
| --- | --- | --- |
| 页头 | 站点品牌（点击回首页）、学科导航（数学 / 语文 / 英语，未开放学科带「建设中 / Soon」标记）、GitHub 源码图标、深浅色切换、中英文切换 | 外壳 |
| 页尾 | MIT 许可、源码仓库链接、本地生成说明、版权 | 外壳 |
| 正文 | 各学科自己的内容与出题逻辑 | 各页面 |

## 页面接入约定

1. `<body data-page="home|math|chinese|english">`，外壳据此设置导航 `aria-current`，并对语文 / 英语导航项追加「建设中 / Soon」标记。
2. 预留占位容器：`<div id="site-header"></div>` 与 `<div id="site-footer"></div>`，位置即渲染位置。
3. 引入顺序：jQuery（CDN）→ `assets/site-shell.js` → 页面自己的脚本。
4. 正文文案国际化：给元素加 `data-shell="key"`，再在页面内 `SiteShell.extendI18N({ zh: {...}, en: {...} })` 注册词条；切换语言时外壳按 `data-shell` 统一替换文本。数学页保留自己的 `data-i18n` 体系，两套互不干扰。
5. 对外契约：`window.SiteShell` 暴露 `lang / theme / setLang / setTheme / toggleTheme / extendI18N / t`；语言与主题变更分别派发 `site:lang`、`site:theme` 自定义事件（`detail.lang` / `detail.theme`），页面按需监听（`$(document).on('site:lang', fn)` 与 `document.addEventListener('site:lang', fn)` 都能收到）。
6. 写法约定：全站脚本的 DOM 查询、文本刷新、属性与 class 切换、节点创建、事件绑定统一用 jQuery（`$('[data-i18n]').each(...)`、`.attr({...})`、`.toggleClass()`、`$(document).on(...)`、`$('<span class="nav-tag"></span>')` 等）。仅以下场景保留原生 API：CSS 自定义属性写入（jQuery `.css()` 不支持 `--x`，用 `el.style.setProperty`）、`MediaQueryList` / `ResizeObserver` 订阅、`CustomEvent` 派发、`canvas` 2D 测量、`localStorage` / `URL.createObjectURL`。
7. 偏好存储键沿用 `mathgen.lang.v1`、`mathgen.theme.v1`，与数学页历史偏好共用；各页 `<head>` 内联脚本先读主题再渲染，避免深色模式闪白。
8. 打印 / 导出时 `.site-header`、`.site-footer` 由 `@media print` 隐藏，页头页脚不进练习卷。
