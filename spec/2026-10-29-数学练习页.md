原「计算题生成器」应用本体，改为多学科站点下的一个学科页面，功能不变。

## 页面规格

- `<title>` / `description` / `keywords` / Open Graph / JSON-LD / canonical 指向 `https://quietdw.github.io/primary-worksheet/math-practice-generator.html`。
- 返回首页、中英文切换、深色模式统一由通用页头承担，页面内部不再保留重复入口；页面监听 `site:lang` 事件同步自身文案。
- 页面自身仍管理参数、出题、预览、导出；不依赖首页或其他学科页。
- 功能范围：运算类型、运算数量（2–4 个数字）、整数 / 小数、负数限制、数字与结果范围、题量 1–2000、种子、2/3/4 列 × 20/25/30 行、字号、表头、答案显示、Word 题目卷 / 答案卷、打印或另存 PDF、导出网页。

## 出题逻辑约束

- 除法按整数商反推除数，整数模式下保证整除，不出现 `÷1`、`86 ÷ 86` 这类无意义题。
- 小数模式下连乘 / 连除的中间结果按小数位数对齐，答案不出现四五位小数。
- 负数限制在构造阶段保证，不靠生成后重试过滤。
- 同一张卷内不出现重复算式。
- 出题随机源由 `cfg.seed` 经 FNV-1a 哈希后喂给 mulberry32 得到，同种子 + 同参数生成同一张卷；种子首次访问随机生成并存进本地配置。
- 「换一批」与「重置」都会换新种子，否则同种子只会重复出同一份卷子；改参数不换种子，便于在同一份卷子上增减题量。

## 实现约束

- 单文件（HTML + CSS + JS），零构建、无打包步骤。
- 页面 DOM 操作与事件绑定走 jQuery；出题引擎保持纯函数，不碰 DOM。
- 预览区按页拼 HTML 字符串后一次性 `$('#paper').html(...)` 写入，避免逐题创建节点。
- 拼装导出用的 HTML 字符串时，禁止在源码中出现连续的 `</body>`、`</script>` 字面量（用 `'</bo' + 'dy>'` 这类拼接），否则 Live Server 之类的自动注入脚本会把主脚本提前闭合。
